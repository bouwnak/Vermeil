🗣 “Hey Siri, Vermeil” (iPhone)

Apple doesn't let any app replace Siri or listen in the background, but Siri can hand your words to Vermeil:

  1. Open the Shortcuts app → +.
  2. Add Dictate Text.
  3. Add Get Contents of URL: URL …, Method POST, Headers: X-Vermeil-Key = , Request Body File → Dictated Text.
  4. Add Speak Text (Contents of URL).
  5. Name the shortcut Vermeil. Now say “Hey Siri, Vermeil”.

Use the Tailscale connection on your computer for this - its address never changes. The free quick link changes each time the computer restarts.

🤖 Android: “Hey Google” and the assistant button

Android doesn't let a web app become the phone's assistant or keep the mic on in the background. What works today:

  • Install Vermeil to the home screen (above), open it, and turn on hands-free. Keep the screen on.
  • Or make a shortcut with an automation app (e.g. HTTP Shortcuts): POST your words to the same address as the iPhone shortcut with the X-Vermeil-Key header, and read the reply aloud.
